# Backend README

This document provides an overview of the backend for the Streamitra project. It includes information on the structure, setup, and usage of the backend code.

# Stack

The backend is built using Node.js and Express. It relies on npm for package management and follows a standard project structure for a Node.js backend.

## Starting the Backend

To start the backend server, follow these steps:

1. ssh into the server:
   ```bash
   ssh [netID]@coms-3090-060.class.las.iastate.edu
   ```

2. Navigate to the backend directory:
   ```bash
   cd /home/sc_ug_1/Backend
   ```

3. Install the required dependencies:
   ```bash
   npm install
   ```

4. Start the server:
   ```bash
   npm start
   ```

The backend server should now be running and accessible at the specified port (default is `3000`).
